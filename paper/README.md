# Paper Artifacts

The manuscript is maintained in two source forms:

- [`report.md`](report.md) for readable review and version control.
- [`paper.tex`](paper.tex) for conference-style compilation.

The compiled [`paper.pdf`](paper.pdf) is a snapshot of the current draft. The
headline claims are supported by the selected JSON artifacts in `results/` and
the scripts listed in the root README.

The manuscript is not yet submitted or peer reviewed. PolitiFact model results,
three-seed significance comparisons, and the limitations of per-node drift
features should not be presented as stronger evidence than the paper states.
